# DAI Dubber Khmer Android (starter)

Experimental Android application with dark UI, SRT import/editing and Android TextToSpeech preview. **Export MP4 is not implemented.** Khmer male/female voices depend on installed TTS engine and are not guaranteed.

## Build
GitHub Actions > Build Android debug APK > latest successful run > Artifacts. This is a debug/testing build, not a finished dubbing app.

The project requires Android SDK 35, JDK 17, Gradle 8.9. No API keys should be committed.
