DubStudio KH Pro Mobile — Android APK Build
============================================
1. ដំឡើង Android Studio (មាន Android SDK 35 និង JDK 17) លើ Windows។
2. Android Studio → Open → ជ្រើស Folder "android" នេះ។
3. បើក Project / Sync Gradle (ត្រូវមានអ៊ីនធឺណិតសម្រាប់ dependencies)។
4. Build → Build APK(s) ឬ Run លើ Android Emulator / USB debugging។
5. APK Debug នៅ android/app/build/outputs/apk/debug/app-debug.apk

Alternative: ចុច BUILD_APK_WINDOWS.bat នៅក្នុង Folder android បន្ទាប់ពីដំឡើង Android SDK និង Java 17។

ចំណាំ៖ APK នេះត្រូវការ AI Backend មុនប្រើសេវា AI ពិត។
